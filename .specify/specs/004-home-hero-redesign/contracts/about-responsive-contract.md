# Home Hero Responsive Contract

## Layout

- Desktop: neural face occupies the existing right-side `.hero__visual` column.
- Tablet: visual scales within the existing Hero layout without changing copy order.
- Mobile: visual follows the existing stacked layout and remains subordinate to the Hero copy and actions.

## Invariants

- SVG preserves its aspect ratio at every viewport.
- No horizontal page overflow is introduced.
- The neural face does not overlap the Hero heading, summary, or actions.
- The visual remains recognizable and does not become unreadably small.
- Unrelated Home sections retain their current layout and styling.

## Review Sizes

Validate at minimum one desktop, one tablet, and one mobile viewport, with the approved About Me reference available for comparison.
